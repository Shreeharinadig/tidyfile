# tidyfile

A multi-tenant platform that turns messy business files (sales exports, invoices, stock sheets) into clean datasets and scheduled reports. It uses LLM-assisted column mapping and, later, a tool-calling report agent.

This is a portfolio project built on **synthetic data**. There are no real customers or real business data in it.

## Quick start

```bash
pip install -r worker/requirements.txt
make test    # Python tests
make eval    # generate the benchmark and score the baseline mapper
```

The full stack needs Docker, Java 21, and Maven:

```bash
cp .env.example .env
make up          # Postgres, API, worker, local AWS emulator
make test-api    # Java tests
```

## Benchmark

`make data` generates 50 files (18 sales, 17 invoices, 15 stock) with realistic mess: title rows above the header, mixed date formats, Indian digit grouping and currency symbols, quantity units, name typos and case noise, duplicate rows, total rows, extra columns, and obscure header names. Every file comes with ground truth. 35 files are the **dev** split and 15 are **held out**. Prompts are tuned on dev only.

Baseline (rule-based mapper, seed 42):

| Group | Files | Columns | Mapping accuracy | Target-column accuracy | Extra columns left unmapped | Header detected |
| --- | --- | --- | --- | --- | --- | --- |
| all | 50 | 399 | 77.9% | 74.5% | 100.0% | 100.0% |
| dev | 35 | 280 | 77.1% | 73.4% | 100.0% | 100.0% |
| held out | 15 | 119 | 79.8% | 76.9% | 100.0% | 100.0% |

The rules miss only obscure headers (for example "Voucher No", "Bal Qty", "Maturity"). Closing that gap is the job of the LLM mapper in week 5. Results are regenerated by `make eval` into `benchmark/results/latest.md`.

The benchmark and the baseline were written by the same person, so treat the baseline as a floor measured on synthetic data, not as a claim about real-world files.

## Local AWS emulator

Local development uses an S3 and SQS emulator. LocalStack stopped shipping a free, token-free image in March 2026, so `docker-compose.dev.yml` pins the last community version. If it no longer pulls, use another emulator on port 4566 or a free LocalStack token. The services only read `AWS_ENDPOINT_URL`, so nothing else changes.

## Costs

Development is free. A deployed demo costs roughly 1,000 to 2,500 rupees a month on AWS once free-tier limits end, so shut it down between demos. Set billing alerts and an LLM spend limit before the first deploy.
